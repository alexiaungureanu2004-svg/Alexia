# StyleUp

Site de prezentare pentru atelierul StyleUp, separat de magazinul LOOMY din repository.

## Rulare locală

Deschide `index.html` într-un browser. Pagina folosește `styles.css`, `app.js` și imaginile livrate remote de site-ul StyleUp.

## Deployment Vercel

Configurează proiectul Vercel `styleup-bridal` cu Root Directory `styleup`. Fișierele site-ului sunt statice, deci nu este necesar un build command. Deployments de preview se generează pentru ramurile non-production.
